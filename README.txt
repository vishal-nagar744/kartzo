Kartzo responsive ecommerce site (same blue theme throughout).
Open index.html in a browser. Assets are in assets/.

Pages:
  index.html       Home
  products.html    Shop / filters / search
  product.html     Product detail
  categories.html  Categories
  deals.html       Deals
  cart.html        Cart (qty + remove)
  checkout.html    Checkout
  orders.html      Orders + track
  wishlist.html    Wishlist
  account.html     Account / profile
  about.html       About + contact

Shared: assets/kartzo.css, assets/kartzo.js
Rebuild pages: node scripts/build-pages.mjs
Tailwind CSS loads from CDN at runtime.
